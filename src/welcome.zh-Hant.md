# Ryu Markdown Viewer 使用指南

點選**編輯**修改 Markdown，按 `Ctrl+S` 儲存。點選資料夾旁的新增檔案按鈕或按 `Ctrl+N` 建立 `.md` 檔案。在編輯器輸入 `/` 顯示 Markdown 指令，繼續輸入以篩選，用滑鼠或 ↑/↓ 和 Enter/Tab 選擇。按 Esc 關閉。


## 編輯和建立文件

尚未儲存的內容在應用程式執行期間保留在記憶體中。關閉分頁、移除資料夾或結束時會詢問是否儲存。外部修改的檔案會受到保護，避免意外覆寫。

## 開啟文件

- **新增資料夾**：點選左下角的按鈕。資料夾中的 `.md` 和 `.markdown` 檔案會顯示在檔案總管中。
- **開啟檔案**：按 `Ctrl+O` 開啟文件。
- **尋找檔案**：按 `Ctrl+P` 搜尋已新增的資料夾。

可以新增多個資料夾。移除資料夾只會取消登錄，不會刪除檔案。

## 閱讀文件

在檔案總管中選擇檔案，即可在分頁中開啟。使用大綱跳至標題，或按 `Ctrl+F` 搜尋內文。點選 **原始碼** 可切換 Markdown 原始碼與預覽。

在其他編輯器中儲存的變更會自動顯示。必要時可點選重新整理按鈕更新檔案清單。

## 圖表

Mermaid 程式碼區塊會顯示為圖表。點選放大按鈕可檢視較大的圖表。

```mermaid
flowchart LR
    A[新增資料夾] --> B[選擇檔案]
    B --> C[閱讀文件]
```

## 公式與程式碼

支援行內公式 $E = mc^2$ 和獨立公式。

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

程式碼區塊支援語法醒目提示與複製。

```typescript
const folders = ['C:/projects', 'D:/notes'];
```

## 快速鍵

| 快速鍵 | 功能 |
| --- | --- |
| Ctrl+N | 新增 Markdown 檔案 |
| Ctrl+S | 儲存文件 |
| Ctrl+O | 開啟檔案 |
| Ctrl+Shift+O | 新增資料夾 |
| Ctrl+P | 尋找檔案 |
| Ctrl+F | 在文件中尋找 |
| Ctrl+B | 顯示 / 隱藏檔案總管 |
| Ctrl+W | 關閉分頁 |
| Ctrl+＋ / Ctrl+－ | 放大 / 縮小 |
| Ctrl+0 | 重設縮放 |

## 設定

點選左下角的齒輪，可選擇 English、한국어、简体中文、繁體中文或日本語。變更立即生效，重新啟動後仍會保留。Markdown 文件的原始語言不會改變。

太陽 / 月亮按鈕可切換主題。已新增的資料夾、開啟的分頁、主題和縮放比例會在下次啟動時還原。
