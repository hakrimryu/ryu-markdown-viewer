# Ryu Markdown Viewer 使用指南

点击**编辑**修改 Markdown，按 `Ctrl+S` 保存。点击文件夹旁的新建文件按钮或按 `Ctrl+N` 创建 `.md` 文件。在编辑器输入 `/` 显示 Markdown 命令，继续输入以筛选，用鼠标或 ↑/↓ 和 Enter/Tab 选择。按 Esc 关闭。


## 编辑和创建文档

未保存的内容在应用运行期间保留在内存中。关闭标签页、移除文件夹或退出时会询问是否保存。外部修改的文件会受到保护，避免意外覆盖。

## 打开文档

- **添加文件夹**：点击左下角的按钮。文件夹中的 `.md` 和 `.markdown` 文件会显示在资源管理器中。
- **打开文件**：按 `Ctrl+O` 打开文档。
- **查找文件**：按 `Ctrl+P` 搜索已添加的文件夹。

可以添加多个文件夹。移除文件夹只会取消注册，不会删除文件。

## 阅读文档

在资源管理器中选择文件，即可在标签页中打开。使用大纲跳转到标题，或按 `Ctrl+F` 搜索正文。点击 **源代码** 可切换 Markdown 源代码与预览。

在其他编辑器中保存的更改会自动显示。必要时可点击刷新按钮更新文件列表。

## 图表

Mermaid 代码块会显示为图表。点击放大按钮可查看更大的图表。

```mermaid
flowchart LR
    A[添加文件夹] --> B[选择文件]
    B --> C[阅读文档]
```

## 公式和代码

支持行内公式 $E = mc^2$ 和独立公式。

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

代码块支持语法高亮和复制。

```typescript
const folders = ['C:/projects', 'D:/notes'];
```

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+N | 新建 Markdown 文件 |
| Ctrl+S | 保存文档 |
| Ctrl+O | 打开文件 |
| Ctrl+Shift+O | 添加文件夹 |
| Ctrl+P | 查找文件 |
| Ctrl+F | 在文档中查找 |
| Ctrl+B | 显示 / 隐藏资源管理器 |
| Ctrl+W | 关闭标签页 |
| Ctrl+＋ / Ctrl+－ | 放大 / 缩小 |
| Ctrl+0 | 重置缩放 |

## 设置

点击左下角的齿轮，可选择 English、한국어、简体中文、繁體中文或日本語。更改立即生效，重启后仍会保留。Markdown 文档的原始语言不会改变。

太阳 / 月亮按钮可切换主题。已添加的文件夹、打开的标签页、主题和缩放比例会在下次启动时恢复。
