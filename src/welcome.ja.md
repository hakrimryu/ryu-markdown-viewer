# Ryu Markdown Viewer ガイド

**編集**で Markdown を変更し、`Ctrl+S` で保存します。フォルダー横の新規ファイルボタンか `Ctrl+N` で `.md` ファイルを作成できます。エディターで `/` を入力すると Markdown コマンドが表示されます。続けて入力して絞り込み、マウスか ↑/↓ と Enter/Tab で選択します。Esc で閉じます。


## 文書の編集と作成

未保存の内容はアプリ実行中のメモリに保持されます。タブを閉じる、フォルダーを解除する、アプリを終了する際は保存を確認します。外部で変更されたファイルの上書きは防止されます。

## 文書を開く

- **フォルダーを追加**：左下のボタンで登録します。配下の `.md` と `.markdown` ファイルがエクスプローラーに表示されます。
- **ファイルを開く**：`Ctrl+O` で文書を開きます。
- **ファイルを検索**：`Ctrl+P` で登録したフォルダー内を検索します。

複数のフォルダーを登録できます。登録を解除してもファイルは削除されません。

## 文書を読む

エクスプローラーでファイルを選ぶとタブで開きます。目次から見出しに移動したり、`Ctrl+F` で本文を検索したりできます。**ソース** で Markdown のソースとプレビューを切り替えます。

別のエディターで保存した変更は自動的に反映されます。必要に応じて更新ボタンで一覧を更新してください。

## 図

Mermaid のコードブロックは図として表示されます。拡大ボタンから大きな表示で確認できます。

```mermaid
flowchart LR
    A[フォルダーを追加] --> B[ファイルを選択]
    B --> C[文書を読む]
```

## 数式とコード

インライン数式 $E = mc^2$ と独立した数式に対応しています。

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

コードブロックには構文の強調表示とコピーボタンがあります。

```typescript
const folders = ['C:/projects', 'D:/notes'];
```

## キーボードショートカット

| キー | 操作 |
| --- | --- |
| Ctrl+N | 新しい Markdown ファイル |
| Ctrl+S | 文書を保存 |
| Ctrl+O | ファイルを開く |
| Ctrl+Shift+O | フォルダーを追加 |
| Ctrl+P | ファイルを検索 |
| Ctrl+F | 文書内を検索 |
| Ctrl+B | エクスプローラーを表示 / 非表示 |
| Ctrl+W | タブを閉じる |
| Ctrl+＋ / Ctrl+－ | 拡大 / 縮小 |
| Ctrl+0 | ズームをリセット |

## 設定

左下の歯車から English、한국어、简体中文、繁體中文、日本語を選択できます。変更はすぐに反映され、再起動後も引き継がれます。Markdown 文書自体の言語は変更されません。

太陽 / 月のボタンでテーマを切り替えます。登録したフォルダー、開いているタブ、テーマ、ズームも次回の起動時に復元されます。
