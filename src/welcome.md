# Ryu Markdown Viewer 사용 안내

**편집**을 눌러 Markdown을 수정하고 `Ctrl+S`로 저장하세요. 폴더 옆 새 파일 버튼이나 `Ctrl+N`으로 `.md` 파일을 만들 수 있습니다. 편집창에서 `/`를 입력하면 Markdown 명령어가 표시됩니다. 이어서 입력해 목록을 좁히고, 마우스 또는 ↑/↓와 Enter/Tab으로 선택하세요. Esc로 닫을 수 있습니다.


## 문서 편집과 새 파일 만들기

저장 전 편집 내용은 앱 실행 중 메모리에 유지됩니다. 탭 닫기·폴더 등록 해제·앱 종료 시 저장 여부를 확인합니다. 외부에서 바뀐 파일은 실수로 덮어쓰지 않도록 저장을 중단합니다.

## 문서 열기

- **폴더 추가**: 왼쪽 아래에서 폴더를 등록합니다. 하위 폴더의 `.md`, `.markdown` 파일만 탐색기에 표시됩니다.
- **파일 열기**: `Ctrl+O`로 문서 하나를 선택합니다.
- **파일 찾기**: `Ctrl+P`로 등록한 폴더 안의 파일을 검색합니다.

폴더를 여러 개 등록할 수 있습니다. 폴더 옆의 ×는 등록만 해제하며 실제 파일은 삭제하지 않습니다.

## 문서 읽기

왼쪽에서 파일을 선택하면 탭으로 열립니다. 오른쪽 목차로 제목을 찾아가거나, `Ctrl+F`로 본문을 검색하세요. 위쪽의 **원문** 버튼은 Markdown 텍스트를 표시합니다.

외부 에디터에서 저장한 변경 사항은 자동으로 반영됩니다. 목록이 갱신되지 않으면 탐색기의 새로고침 버튼을 누르세요.

## 다이어그램

Mermaid 코드 블록은 그래프로 표시합니다. 그래프 오른쪽 위의 확대 버튼으로 큰 창에서 확인할 수 있습니다.

```mermaid
flowchart LR
    A[폴더 추가] --> B[파일 선택]
    B --> C[문서 읽기]
```

## 수식과 코드

인라인 수식 $E = mc^2$와 블록 수식을 지원합니다.

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

코드 블록은 언어에 따라 구문을 강조하고 복사 버튼을 표시합니다.

```typescript
const folders = ['C:/projects', 'D:/notes'];
// 등록한 폴더에서 Markdown 파일을 찾습니다.
```

## 단축키

| 단축키 | 기능 |
| --- | --- |
| Ctrl+N | 새 Markdown 파일 |
| Ctrl+S | 문서 저장 |
| Ctrl+O | 파일 열기 |
| Ctrl+Shift+O | 폴더 추가 |
| Ctrl+P | 파일 찾기 |
| Ctrl+F | 본문 찾기 |
| Ctrl+B | 탐색기 표시 / 숨기기 |
| Ctrl+W | 탭 닫기 |
| Ctrl+＋ / Ctrl+－ | 본문 확대 / 축소 |
| Ctrl+0 | 본문 100% |

## 설정

왼쪽 아래 기어 버튼에서 English, 한국어, 简体中文, 繁體中文, 日本語를 선택할 수 있습니다. 변경한 언어는 즉시 적용되며 앱을 껐다 켜도 유지됩니다. Markdown 문서 자체의 언어는 바뀌지 않습니다.

밝은 테마와 어두운 테마는 왼쪽 아래의 해·달 버튼으로 전환합니다. 등록한 폴더와 열린 문서, 테마, 확대 비율은 다음 실행 때 복원됩니다.
